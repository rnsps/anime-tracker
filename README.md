# anime-tracker
A Python command-line application for tracking anime, ratings, viewing status and episode progress.

## Current Features

- Add anime titles
- Record ratings
- Track viewing status
- Track episode progress
- Validate user input
- Handle invalid numerical inputs using exception handling

## Built With

- Python

## What I Learned

This project has helped me practise:
- Functions
- Lists and dictionaries
- Loops
- Input validation
- Exception handling
- Breaking larger problems into smaller functions
